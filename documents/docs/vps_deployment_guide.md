# Cloud VPS + Docker/Coolify Deployment Guide

এই গাইডলাইনে ধাপে ধাপে দেখানো হয়েছে কিভাবে একটি Cloud VPS-এ Coolify ব্যবহার করে আপনার Node.js + TypeScript (Monorepo), PostgreSQL এবং Redis প্রোজেক্টটি ডকারাইজড (Dockerized) পরিবেশে অত্যন্ত সহজে ডেপ্লয় এবং ম্যানেজ করবেন।

> [!TIP]
> **Coolify কী?**
> Coolify হলো একটি ওপেন-সোর্স, সেল্ফ-হোস্টেড প্ল্যাটফর্ম যা Vercel, Heroku বা Netlify এর বিকল্প হিসেবে কাজ করে। এটি আপনার সার্ভারে ইন্সটল করার পর, আপনি গিটহাব থেকে সরাসরি এক ক্লিকে যেকোনো প্রজেক্ট, ডেটাবেস এবং সার্ভিস ডেপ্লয় করতে পারবেন। এটি ব্যাকএন্ডে স্বয়ংক্রিয়ভাবে Docker ব্যবহার করে।

---

## Step 1: Cloud VPS ক্রয় এবং ডোমেইন সেটআপ

### ১.১ সার্ভার ক্রয় করা
আপনার প্রজেক্টের স্কেল অনুযায়ী যেকোনো একটি ক্লাউড প্রোভাইডার থেকে VPS কিনুন।
- **প্রোভাইডার:** DigitalOcean, Vultr, Hetzner (Hetzner সবচেয়ে সাশ্রয়ী এবং পাওয়ারফুল), অথবা AWS।
- **অপারেটিং সিস্টেম (OS):** Ubuntu 22.04 LTS অথবা Ubuntu 24.04 LTS।
- **রিকোয়ারমেন্ট:** কমপক্ষে 2GB RAM এবং 2 Core CPU (যেহেতু Database, Redis, Node, এবং React একসাথে চলবে)।

### ১.২ ডোমেইন এবং সাব-ডোমেন DNS সেটআপ
আপনার ডোমেইন প্যানেলে (যেখান থেকে ডোমেইন কিনেছেন, যেমন Namecheap বা Cloudflare) গিয়ে নিচের DNS রেকর্ডগুলো যুক্ত করুন:
- **A Record:** Name: `@` (বা আপনার ডোমেইনের নাম), Value: `আপনার_VPS_এর_IP_Address`
- **Wildcard A Record (খুবই জরুরি):** Name: `*`, Value: `আপনার_VPS_এর_IP_Address`
  > Wildcard রেকর্ড অ্যাড করার ফলে আপনি ভবিষ্যতে যেকোনো সাব-ডোমেন (যেমন: `payroll.SanSuite.com`) তৈরি করলেই তা সরাসরি আপনার সার্ভারে হিট করবে।

---

## Step 2: সার্ভারে Coolify ইন্সটল করা

আপনার সার্ভারে SSH দিয়ে লগিন করুন (যেমন: `ssh root@your_server_ip`) এবং নিচের কমান্ডটি রান করুন:

```bash
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
```

এই কমান্ডটি স্বয়ংক্রিয়ভাবে আপনার সার্ভারে Docker এবং Coolify এর প্রয়োজনীয় সব সার্ভিস ইন্সটল করে দিবে। ইন্সটল হতে ১০-১৫ মিনিট সময় লাগতে পারে।

ইন্সটলেশন শেষ হলে আপনার ব্রাউজারে গিয়ে লিখুন:
`http://আপনার_VPS_এর_IP_Address:8000`

এখানে আপনি Coolify এর ড্যাশবোর্ড দেখতে পাবেন। প্রথমবার লগিন করার জন্য একটি অ্যাডমিন অ্যাকাউন্ট তৈরি করে নিন।

---

## Step 3: Database এবং Redis সেটআপ

আপনার অ্যাপ্লিকেশন রান করার আগে ডেটাবেসগুলো রেডি করতে হবে।

### ৩.১ PostgreSQL ডেপ্লয়
1. Coolify ড্যাশবোর্ডে গিয়ে **+ Create New Resource** এ ক্লিক করুন।
2. **Databases** অপশন থেকে **PostgreSQL** সিলেক্ট করুন।
3. আপনার ডেটাবেসের নাম, ইউজারনেম এবং পাসওয়ার্ড দিয়ে `Save` করুন এবং **Start** বাটনে ক্লিক করুন।
4. মাত্র কয়েক সেকেন্ডের মধ্যে একটি ডেডিকেটেড ডকার কন্টেইনারে আপনার ডেটাবেস চালু হয়ে যাবে। Coolify আপনাকে ডেটাবেসের একটি ইন্টারনাল URL (যেমন `postgresql://user:pass@coolify-db:5432/dbname`) দিয়ে দিবে, যা আপনি আপনার Node.js `.env` ফাইলে ব্যবহার করবেন।

### ৩.২ Redis ডেপ্লয়
1. পুনরায় **+ Create New Resource** এ ক্লিক করুন।
2. **Databases** অপশন থেকে **Redis** সিলেক্ট করুন।
3. সেভ করে Start করুন। 

> [!NOTE]
> এই ডেটাবেসগুলো ইন্টারনাল ডকার নেটওয়ার্কে থাকবে, যা বাহিরের দুনিয়া থেকে সরাসরি এক্সেস করা যাবে না, ফলে এটি অত্যন্ত সুরক্ষিত। আপনার Node.js অ্যাপ সরাসরি ইন্টারনাল নেটওয়ার্কের মাধ্যমে এগুলোর সাথে কানেক্ট করবে।

---

## Step 4: GitHub Repository কানেক্ট করা

1. Coolify ড্যাশবোর্ড থেকে **Sources** মেনুতে গিয়ে **+ Add GitHub App** এ ক্লিক করুন।
2. Coolify কে আপনার গিটহাব অ্যাকাউন্টের সাথে কানেক্ট করুন এবং আপনার `imedicare` (বা SanSuite) রিপোজিটরির পারমিশন দিন।
3. এর ফলে আপনি গিটহাবে কোড `push` করলেই সার্ভারে স্বয়ংক্রিয়ভাবে নতুন কোড ডেপ্লয় (CI/CD) হয়ে যাবে।

---

## Step 5: Node.js + React (Monorepo) ডেপ্লয় করা

যেহেতু আপনার প্রোজেক্টটি একটি Monorepo, তাই আমরা Client এবং Server আলাদাভাবে ডেপ্লয় করতে পারি অথবা একই ডকার ইমেজে রান করাতে পারি। 

Coolify **Nixpacks** টেকনোলজি ব্যবহার করে, যার মানে হলো আপনার কোনো `Dockerfile` লেখার প্রয়োজন নেই। এটি আপনার `package.json` দেখেই বুঝে নিবে কিভাবে অ্যাপটি রান করতে হবে।

### ৫.১ Backend API সার্ভার ডেপ্লয়মেন্ট
1. **+ Create New Resource** -> **Application** -> **GitHub** সিলেক্ট করুন।
2. আপনার রিপোজিটরি এবং মেইন ব্রাঞ্চ সিলেক্ট করুন।
3. সেটিংসে গিয়ে নিচের অপশনগুলো ঠিক করুন:
   - **Build Command:** `npm run build:server` (বা আপনার সার্ভার বিল্ড কমান্ড)
   - **Start Command:** `npm run start:server`
   - **Base Directory:** `/` (বা যে ফোল্ডারে `package.json` আছে)
4. **Environment Variables:** এখানে আপনার `.env` ফাইলের সব ডেটা (Database URL, Redis URL) বসিয়ে দিন।
5. **Domains:** এখানে আপনার এপিআই ডোমেইনটি বসান (যেমন: `https://api.SanSuite.com`)। 
6. **Deploy** বাটনে ক্লিক করুন। Coolify স্বয়ংক্রিয়ভাবে ফ্রি SSL সার্টিফিকেট (Let's Encrypt) জেনারেট করে আপনার ডোমেইনটি সার্ভারে লাইভ করে দিবে।

### ৫.২ Frontend (React/Vite) ডেপ্লয়মেন্ট
1. পুনরায় একটি নতুন অ্যাপ্লিকেশন তৈরি করুন।
2. একই রিপোজিটরি সিলেক্ট করুন।
3. সেটিংসে গিয়ে:
   - **Build Command:** `npm run build:client` 
   - **Start Command:** Frontend এর জন্য সাধারণত স্ট্যাটিক ফাইল রেন্ডার করতে হয়। Coolify তে আপনি `Static Web Server` সিলেক্ট করতে পারেন অথবা Nginx এর মাধ্যমে সার্ভ করতে পারেন।
4. **Domains:** এখানে আপনার মূল ডোমেইন বা সাবডোমেইনগুলো (যেমন: `https://app.SanSuite.com`) বসান।
5. **Deploy** এ ক্লিক করুন।

## Step 6: সাব-ডোমেন রাউটিং ম্যানেজ করা (Subdomain Routing)

আপনি যদি Express.js এর ভেতরেই সব সাব-ডোমেন হ্যান্ডেল করতে চান, তবে Frontend এবং Backend কে একটিমাত্র অ্যাপ্লিকেশন হিসেবে ডেপ্লয় করে সেটির ডোমেইন সেটিংসে আপনার মূল ডোমেইন এবং Wildcard ডোমেইন বসিয়ে দিন:

- **Domains field in Coolify:** `https://SanSuite.com, https://*.SanSuite.com`

এর ফলে Nginx (যেটি Coolify ম্যানেজ করে) সমস্ত ট্রাফিক আপনার Node.js সার্ভারে পাঠিয়ে দিবে। এরপর আপনার কোডের `req.hostname` লজিক অনুযায়ী ইউজারকে তার নির্দিষ্ট ড্যাশবোর্ড বা ডেটা দেখানো হবে।

> [!IMPORTANT]
> **অটো স্কেলিং এবং আপডেট:** 
> Coolify তে Webhook সেটআপ করা থাকে। আপনি যখনই গিটহাবে নতুন কোড `push` করবেন, Coolify জিরো-ডাউনটাইমে (Zero-downtime deployment) নতুন কন্টেইনার বিল্ড করে পুরনোগুলো রিপ্লেস করে দিবে। আপনার ইউজাররা বুঝতেই পারবে না যে সাইট আপডেট হয়েছে।
