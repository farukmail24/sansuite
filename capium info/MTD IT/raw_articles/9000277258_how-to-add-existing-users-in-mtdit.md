### How to add existing users in MTDIT

			Print

	Modified on: Thu, 18 Jun, 2026 at 11:16 AM

		First, navigate to My Admin > Users and assign the MTDIT module to the specific user. Then ask the user to log in with their credentials and navigate to the MTDIT module. This will trigger an automatic synchronization between MTDIT and the main platform, and the user will then appear in the Users section within MTDIT.
