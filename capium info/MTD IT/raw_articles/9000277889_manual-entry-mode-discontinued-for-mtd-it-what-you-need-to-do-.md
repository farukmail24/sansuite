### Manual Entry Mode Discontinued for MTD IT: What You Need to Do?

			Print

	Modified on: Fri, 17 Jul, 2026 at  9:51 AM

		From 21 July 2026, Manual Entry mode is no longer available in the MTD IT module. After this date, you will not be able to add transactions directly within MTD IT using Manual Entry.

Your existing records are not affected and will not be lost. Any clients using Manual Entry will need to have moved onto the Bridging workflow before the first quarterly submission deadline of 7 August 2026, so that submissions are based on Bridging data rather than Manual Entry.

### Why this is changing

Manual Entry was originally introduced as a simple way to record individual transactions directly within MTD IT for clients with a low volume of transactions.

We have reviewed this with our compliance team and consulted HMRC directly, and have taken the decision to consolidate on the Bridging workflow for all MTD IT digital records going forward. Working from a single file for each client keeps records together in one place, rather than split across Manual Entry and other sources, which reduces the room for error as records are built up and submitted each quarter.

Bridging also gives you more flexibility, including the ability to export data from other software and import it straight into Capium.

### Next steps

If you have clients using Manual Entry, see MTD IT: Moving from Manual Entry to Briding, Step by Step for the full walkthrough, covering both a standard submission and a resubmission where a quarter has already been submitted using Manual Entry data.
