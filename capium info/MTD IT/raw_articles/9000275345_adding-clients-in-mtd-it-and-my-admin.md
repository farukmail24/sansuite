### Adding Clients in MTD IT and My Admin

			Print

	Modified on: Wed, 18 Mar, 2026 at 12:16 PM

		The MTD IT module does not automatically pick up newly created clients from MY ADMIN yet.

Existing clients may appear in MTD IT only if they were previously used (e.g., for Self Assessment or earlier workflows).

Important note on duplicates:In future, when the client import from MY ADMIN to MTD IT is enabled, if you’ve already manually added the same client in MTD IT, it may show as a duplicate in the list.What you should do now:

Add new clients in MY ADMIN Then manually create them again in MTD IT (for now)
