### MTD IT - Adding New Clients

			Print

	Modified on: Mon, 27 Apr, 2026 at  5:20 PM

This article explains how to add clients within the MTD IT module in Capium. Please note that the workflow for adding clients has changed. Clients can no longer be imported directly from the Self Assessment module and must now be added from within the MTD IT module itself.

### 
Adding a New Client Directly in MTD IT

If you need to add a brand new client to the MTD IT module, you can do so directly from within the module.

Navigation > MTD IT > Add Client 

Alternatively you can click here :Add Client

Click Add Client.
Enter the required client details to create the client within the system.

Please see GIF for reference 

### 

Adding an Existing Client via Capium 365

If a client already exists and has been imported into the MyAdmin module, you will need to enable the MTD IT module for them via Capium 365.

Navigation > Capium 365

Alternatively you can click here :Capium 365 Client Portal 

From the Capium 365 Client Portal, you will see a list of all your clients.
Navigate to the Individuals client type and select the relevant individual.
Ensure the following mandatory fields are completed for that individual:UTR Number
National Insurance Number
Full Name
Email Address

Once all mandatory fields have been filled in, go to the Module section.
Enable the MTD IT module for that individual

Please see GIF for reference 

Please note: Only individuals can currently be brought into the MTD IT module. Sole traders must first be linked to an individual before they can be added to the module.

### 
Linking Sole Traders to Individuals

If you have sole trader clients that you need to bring into the MTD IT module, you will need to link the sole trader to an individual first.

For full guidance on how to do this, please refer to our dedicated article: Linking Sole Traders and Individuals.
