### How to add bank details to the invoices

			Print

	Modified on: Tue, 26 Mar, 2024 at  1:54 PM

		1. Select the Doc invoice template.

For adding the bank details to the invoices.

Navigation: Bookkeeping >> Client specific >> Settings >> Company Info >> Settings (tab) >> Tick Use Doc (word) Invoice Template >> Save.

2. Add or edit template files.

Once the doc invoice template is selected.

Navigation: Settings >> General Settings >> Invoice Templates >> Add template (if you want to add a new template) or Edit template (for editing the existing one) >> Select the bank from the dropdown >> Save.
