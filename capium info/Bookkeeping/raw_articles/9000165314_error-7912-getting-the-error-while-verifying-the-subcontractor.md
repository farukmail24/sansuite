### Error 7912: Getting the error while verifying the subcontractor

			Print

	Modified on: Mon, 25 Oct, 2021 at  3:02 PM

The error will get generated when the contractor’s work reference in a verification request is invalid. Please correct the reference and resend the request. 

To do this please go to :

Navigation: Bookkeeping >> Select Client >> CIS >> Subcontractor

Under action please click the edit dropdown.

Then edit the work reference as necessary
