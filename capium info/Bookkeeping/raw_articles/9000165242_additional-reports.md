Additional Segment

Recent Transactions

User log

Email log

Account details

Nominal ledger

Recent Transaction: You need to select the username from the drop, then select the date from the calendar and then click on the search icon. List of the recent transaction based on search would be displayed. You can also export the report as PDF and excel. This page contains Date, time, Ref. No., Particular, username and Action such as create, delete, update, other. By clicking on Ref. No. you can view detail. 

User log: You have search field then, you need to select the username from the drop, then select the date from the calendar, select action from the drop-down as create, delete, update, other and then click on the search icon. List of the recent transaction based on search would be displayed. You can also export the report as PDF and excel. This page contains Date, time, description, username and Action such as create, delete, update, other.

Email log: You have search field then; you need to select the date from the calendar and click on the search icon and Email log will be displayed containing details as Date, sent to, subject, Attachment, status, and view.

Account details: You can select Account from the drop-down, a select period such as All, Current month, last month, Current year, last year, depending on a period was chosen date would be fetched and click on the search icon and related details would be displayed. You can also export the report as PDF and excel. This page contains Date, Particular, Reference, Type, Ref. No., Debit, Credit, and Balance.

Nominal Ledger: Select period such as All, Current month, last month, Current year, last year, depending on a period chosen date would be fetched, Enter the account code and click on the search icon and related details would be displayed. You can also export the report as PDF and excel. This page contains Date, Particular, Reference, Type, Ref. No., Debit, Credit.
