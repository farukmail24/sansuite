### How to Submit VAT

			Print

	Modified on: Wed, 27 Sep, 2023 at  4:40 PM

		Location:  Bookkeeping module > Dashboard > Client specific > VAT > Submit VAT

Refer to the link

Help/Guide: 

Submitting your VAT Return is done in 4 steps;

1) Set up VAT Period

2) Include/Exclude Transactions

3) Review Return

4) HMRC Gateway Details 

1) Set up VAT Period 

Once in the VAT section, click on “+VAT period” to set up the VAT period - as shown in the image below.

To set up period you need to enter the date from the calendar, you can also enter any description and you can tick “De-registered for VAT” checkbox if this is your last VAT submission. This is only needed when you have already cancelled your VAT registration from HMRC’s end. Then click on Save and Next.

2) Include/Exclude Transactions

Here you need to choose which transactions to be included or excluded from VAT return. For this, choose between Sales & Purchase tabs and click '+Include' to add the transactions. Once done, click the Next button.

3) Review Return

You can review the return, make edits by clicking on edit and view Audit report by clicking on view Audit report. Once ready to proceed with submission, click the 'Submit to Capium' option to save a copy of the return to Capium then click on ‘continue for HMRC submission’

4) HMRC Gateway Details 

You need to fill HMRC credentials i.e. user ID and password and If you are an agent then tick checkbox ‘I am an agent’ and click on submit to HMRC icon. Still, you may click on the finish icon in case you are not sure to submit the return to HMRC

Note

For Cash Based Normal Scheme, you will need to enable the Audit Report manually by ticking the checkbox within VAT Return Report page as shown below
