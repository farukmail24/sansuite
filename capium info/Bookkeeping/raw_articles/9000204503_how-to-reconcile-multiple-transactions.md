### How to reconcile multiple transactions

			Print

	Modified on: Tue, 20 Jul, 2021 at  4:43 PM

		Location:

Bank >> Dashboard >> Select bank account >> Find transaction >> Click on 'Select Action' >> Click on 'Multiple Transaction' >> Create multiple receipts / journals as required

Video Tutorial:

Click here to watch how to reconcile multiple transactions 

Help Guide:

Using the navigation panel on the left to go into the bank dashboard 

Select a bank account and then use the search function to find the transaction that needs to be reconciled.

Click on the 'Select Action' drop box and select 'Multiple Transaction'. 

You can then choose how you to reconcile the transaction.

You can either choose to create multiple receipts / payments for one transaction as shown below:

Or you can choose to create a journal entry:

This will give you the abililty to split the transaction and choose how it needs to be reconciled.
