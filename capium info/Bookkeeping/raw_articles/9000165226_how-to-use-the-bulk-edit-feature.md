### How to use the Bulk Edit feature

			Print

	Modified on: Mon, 18 Jan, 2021 at  4:33 PM

		Click here to watch the how to use Bulk Edit

Location: Bookkeeping module > Dashboard > Client specific > Tasks > Bulk Edits

Bulk Edit is a feature which allows you to re-code transactions to other nominal accounts. Head to the navigation above then search for the nominal code which has the transactions you would like to re-code.

Then use the date filters to find the transactions by date. Once you have your list of transactions (as shown below) use the checkbox(s) to select the transaction(s) you would like to re-code.
