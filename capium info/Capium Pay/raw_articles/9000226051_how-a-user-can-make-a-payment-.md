### How a user can make a payment?

			Print

	Modified on: Wed, 5 Apr, 2023 at  5:07 PM

		To make payment within Capium Pay.

Navigation: Email

Following the navigation process, a user is able to navigate to a pay portal by clicking the link.

Once performed, a user will be redirected to a pay portal where the full overview can be seen. To proceed with the payment, a user is required to click the 'CapiumPay' blue icon. 

Once performed, a user is able to fill in the required details and proceed with the payment.
