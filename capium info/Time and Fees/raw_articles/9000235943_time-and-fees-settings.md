### Time and Fees - Settings

			Print

	Modified on: Wed, 10 Apr, 2024 at  1:19 PM

		Introduction to Time and Fees Module

Time and Fees is designed to Manage the Jobs and Tasks in a estimated Time and Fees

Getting Started

Settings

In the Settings Menu, we have the 5 sections below:

My Business

Preferences

Invoices

Estimates

Templates

Integrations

Navigation: Settings>My Business 

https://timeandfees.capium.com/settings/mybusiness

In this section, the company details  will be available and the  admin user will  be able to amend or update the details of the company

Company Name

Company Number

VAT Number

Address

Contact

Upload logo

 Preferences:

Navigation: Settings> Preferences

https://timeandfees.capium.com/settings/preferences

In this section, the admin can choose the preferences based on the requirement

    The information below can be updated in the Preferences section by the Admin user

Start Week on

Default Capacity Hours per week

Timesheet Due on

Timesheet Reminder

Approval Reminder 

Time Format

Time Mode

Demo Data

Navigation: Settings> Demo Data

https://timeandfees.capium.com/settings/demodata

In this section  you have the demo information across the module,  the admin user can view data from one section to another section while you're in demo mode. 

Invoices

Navigation: Settings>> Invoices

https://timeandfees.capium.com/settings/invoice

In Invoices the admin can choose the preferences for Invoices. It includes the 

Invoice ID generation type: In invoice generation id there are 2 option to select either Autogenerate or Add Manually 

Payment Method

Payment Due Term 

VAT details

Sending Recurring invoices option

Footer

Navigate> Settings> Invoices

Under this section the admin can select the table columns as the columns and its naming that you select  will be applied to all the 'Fees' sections by default. If you wish to change any particular invoice or recurring invoice or estimate fields, you can do that from respective pages at detailed grid

Estimates:

 Navigation: Settings> Estimates

https://timeandfees.capium.com/settings/estimate

In this section, the admin can select the Estimate ID generation type (Autogenerate or Add Manually) and Prefix and suffix of Estimate of Fees for the clients along with the Footer

 Templates

Navigation: Settings> Templates

https://timeandfees.capium.com/settings/template

In this section, the Capium will be providing the default templates for the below-mentioned sections. The  user can make the changes and use the available Tags accordingly

Invoices

Payments

Reminders

Estimates

Timesheets

Expense

Signature

Navigation: Settings>> Templates>>Signature for all emails

Integrations:

 Navigation:  Settings>> Integrations

https://timeandfees.capium.com/settings/integration

In this Section, the system will show that the Time & Fee module has been integrated with different applications

   The system has been integrated with the following options:

    Email: The user can use the Capium Emails for Time and Fee or use Gmail or Outlook based on the requirement

If you encounter any issues or require further assistance, don't hesitate to reach out to your Onboarding Manager.
