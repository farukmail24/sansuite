### How to change tax-due document template

			Print

	Modified on: Fri, 2 Jun, 2023 at  2:47 PM

		To format a tax-due document template within the Self Assessment module. 

Navigation: Self Assessment > General settings > Document templates

Following the navigation process, a user is able to format a tax-due template using the 'Edit' button, and adding relevant tags. 

Once the process is complete, a user is required to click the 'Save' button to apply all the changes made.
