### How to update the number of trusts made by the same settlor

			Print

	Modified on: Wed, 14 Jul, 2021 at 11:15 AM

		Location:

Self Assessment dashboard >> SA900 >> Select client >> Select return >> In the main form click on 'Trust Type' >> Update the field called 'Number of trusts made by same settlor' 

Video Tutorial:

Click here to watch how to update the number of trusts made by the same settlor

Help Guide:

From the Self Assessment dashboard, go into the SA900 tab and then select a client.

You can either select a return that has already been created to edit it, or create a new return by clicking on 'New SA900'

From the main form click on 'Trust Type' and then update the box next to 'Number of trusts made by same settlor'
