### I need to amend the tax return for 2016-17 can you please tell me how to submit an amended return.

			Print

	Modified on: Mon, 25 Mar, 2019 at  1:47 PM

		You may simply create a copy of the self-assessment return already created from the action drop-down and may change the return type as "amended" and then you may submit the amended return by choosing the option Submit to HMRC from the action drop-down.
