### I need to prepare self-assessment tax return for 2012-13. Is there any option in Capium?

			Print

	Modified on: Mon, 25 Mar, 2019 at  1:55 PM

		You can make self-assessment submissions in Capium starting from the year 2013-14 and not before that. You can submit it in HMRC’s portal.
