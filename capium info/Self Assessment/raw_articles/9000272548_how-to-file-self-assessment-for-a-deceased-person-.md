### How to File Self Assessment for a Deceased Person?

			Print

	Modified on: Thu, 27 Nov, 2025 at  3:03 PM

		This is to formally notify you that there is currently no designated section available to update the assessee regarding the date of death. Therefore, you may kindly reach out to HMRC concerning the submission of the return for the deceased individual.

You may please refer to the link below for further assistance on how to submit a tax return for the deceased.

URL : https://www.gov.uk/self-assessment-tax-returns/returns-for-someone-who-has-died
