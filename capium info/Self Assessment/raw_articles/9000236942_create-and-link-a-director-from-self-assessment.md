### Create and Link a Director from Self-Assessment

			Print

	Modified on: Mon, 18 Mar, 2024 at  4:18 PM

		Click here to watch how to Create and link a Director from the Self Assessment module

Navigation: Self Assessment module >> + Client >> Select the ‘Client Type’ as ‘Individual'.

This integration seamlessly enables users to create and link individual clients from the Self Assessment module to existing limited company(s), as directors. Additionally, it allows for linking of directors already added to the Self Assessment module, with existing limited company(s). 

When creating a new client, select 'Individual' as the 'Client Type'. You can then click on the field 'Assign as Director' on the right and select the limited company(s) you wish to assign this director to.

If the individual is already created in the Self Assessment module, navigate to the client-specific workspace and edit the 'Assessee Details' box to assign him/her as a director of an existing limited company.
