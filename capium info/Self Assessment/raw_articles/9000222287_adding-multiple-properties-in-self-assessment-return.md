### Adding Multiple Properties in Self Assessment Return

			Print

	Modified on: Fri, 9 Dec, 2022 at  9:52 AM

Please Note: Details on adding multiple properties can be seen in the screenshotsTo add multiple properties income and summarise that within your self assessment return please click on this link to be redirected. Alternatively you can also follow the navigation as shown below.  

Navigation: Self Assessment>> Choose the client >> Action>> Edit>>Supplementary Pages>>UK PropertyOnce you have navigated to the above directory, click on the action dropdown and select edit as shown below.

You will now be taken to the self assessment client main screen. 

Step 1: Click the on the green add supplementary page box to ensure that UK property page is added.

Step 2: Click on 'Supplementary Pages' tab and scroll to UK Property.  

Once you scroll to UK property click on edit and you will be taken to the page below:

Option 1: Add multiple furnished holiday lettings

Option 2: Add multiple UK property lettings 

PLEASE NOTE: There are separate tabs in place for UK properties and EEA Properties. 

Option 1: Adding multiple furnished holiday lettings. 

Click on the add multiple UK properties icon. 

You can now fill in the following form (ONE PER PROPERTY) 

Once this is filled in you will be able to add another property until all properties have been added on. 

Once you add multiple properties it will appear as shown on the screen below.

You have the option to remove or edit a property once it is created. 

 Option 2: 

When adding UK rental properties you will have the options as above for adding individual properties. This is shown on the screenshot below. 

Once selected, you will now be able to add income, expenses and profits from each property. 

Once a property is saved the system will automatically let you add another property. The summarised figures will be updated within the forms.

Once you add multiple properties it will appear as shown on the screen below.

You have the option to remove or edit a property once it is created.
