### Change Status for Self-Assessment Return

			Print

	Modified on: Mon, 23 Jan, 2023 at  5:01 PM

Steps:

This will help you to change the status from In-Progress to “Submitted” for the returns which you have created in the Capium but submitted from the Third-Party software. Please note you are require to set up and prepare the self assessment before you can update the status.

Please navigate to the Self-Assessment module
Select the client.
 - Click the + SA100 to add a new self assessment and prepare.
Back In the Client Dashboard, from the Action dropdown, you will have an option “Change Status”
Please click “OK” to update the status
Once the status has been updated, the status of the return will be shown as “Submitted”

Once you have updated the Submission status a pop-up box appears |Click ok.

This will now display the confirmation message as “This return has been submitted through third party.”
