### HMRC Connect error messages

			Print

	Modified on: Fri, 9 Feb, 2024 at  9:24 AM

		HMRC connect doesn't always pull through information from HMRC, this could be for a number of reasons, the error messages are shown below:

Code : NOT_FOUND

Message : Resource was not found

Error Details: NOT_FOUND: 

There is no data available from HMRC for the given UTR number and the tax year.

Data is only available once PAYE reconciliation has completed

Reconciliation starts on or around 6th June and runs for around one million individuals per working night. It is usually completed by the end of November. Unfortunately it is not possible to know when reconciliation will be completed for a specific individual.

Code : SA_UTR_INVALID

Message : The provided SA UTR is invalid

Error Details : SA_UTR_INVALID

The UTR number is invalid.

Code : INVALID_CREDENTIALS

Message : Invalid Authentication information provided

Error Details : There seems to be an issue with the authentication, the token is invalid or has expired.  Please click here to reauthorise

If you would like further clarification please raise a support ticket.
