			Print

	Modified on: Mon, 5 Feb, 2024 at  9:17 AM

		Capium Hub

This Article Provides the Step by Step Guide in Create a client user and access to Hub

Adding Client User 

Navigation: My Admin>User>Add New User

Under this section click on New User and Select  User Type as Client. By this you will be able to add the Client User. Once selected the user type as client populate the relevant fields and Save  

This can be done individually or Import the Users in Bulk using  csv,  populate the relevant fields and upload it.

Access to Hub

Navigation: My Admin>My Subscription>Hub

Under this Section. You can provide the Hub Access to clients using the Hub Access Toggle button as yes/no to your Client.
