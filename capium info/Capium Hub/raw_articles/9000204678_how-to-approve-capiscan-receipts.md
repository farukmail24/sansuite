### How to approve Docscan receipts

			Print

	Modified on: Fri, 23 Jul, 2021 at 11:44 AM

		Location:

Purchases >> Docscan >> Find the transaction >> Using the drop down box select 'Record' >> Select nominal ledger >> Click on save and close. 

Video Tutorial:

Click here to watch how to approve a scanned receipt 

Help Guide:

From the client dashboard, go into 'Purchases' and then 'Docscan'. 

Use the search function to find the scanned receipts. 

Find the transaction and using the drop down box, click on 'Record'.

The system will automatically enter the amount of the receipt onto the invoice as well as attach the scanned receipt. 

The final step is to select the nominal account to post this transaction into and click on 'Save & Close'.
