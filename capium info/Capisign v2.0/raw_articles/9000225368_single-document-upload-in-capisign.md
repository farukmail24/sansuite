### Single document upload in Capisign

			Print

	Modified on: Mon, 17 Jul, 2023 at  1:29 PM

		To upload a document in Capium to be signed. 

Please Note:

CapiSign only PDF files to be e-signed. 

When signing from a smartphone, please use the landscape mode.

Help/Guide

Navigation: Capisign > Sign Documents > Sign & Send > Upload Document

Following navigation process, a user is able to upload a document into Capisign module to get it signed by client. 

Once performed, a user is able to select a file from the list and upload it into the system as shown above.

Once processed, a user is required to click the “Next button” to upload a document.

Once performed, a user is required to add signatories to perform the upload.

Once it has been done, a user is able to drag across relevant tags, add or delete signatories and review the document.

Once performed, a user is able to add a message to Signatories, set reminders and send a document to a client.
