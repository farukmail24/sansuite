### Multiple document upload in Capisign

			Print

	Modified on: Fri, 8 Mar, 2024 at 12:20 PM

		To upload multiple documents in Capium to be signed. 

Please Note: documents can be signed only using a web version. Not supported on smartphones. Only PDF files are supported. 

Help/Guide

Navigation: Capisign > Sign Documents > Sign & Send > Upload Document

Following navigation process, a user is able to upload multiple documents into Capisign module to get it signed.

Once performed, a user is able to select files from the list and upload them into the system as shown above. 

Once processed, a user is required to click “Next button” to upload documents.

Once performed, a user is required to add signatories to perform the upload.

Once it has been done, a user is able to drag across relevant tags, add or delete signatories, review the documents, set reminders, add a message for Signatories and send the documents to a client.
