### How to rename a document within Capisign

			Print

	Modified on: Tue, 3 Sep, 2024 at  3:20 PM

		To rename a document on the overview page within Capisign.

Please note: the signed document cannot be renamed.

Navigation: Capisign > Overview

Following the navigation process, a user is able to rename an uploaded file by clicking the “Three dots” and selecting the “Rename” option.

Once performed, a window with the "Rename" option will pop up, allowing a user to rename a document.

Once performed, a user will be able to save the progress and the changes will be displayed for a selected document.

Important to note: Currently if there is a dot symbol (.) within the name of the document it might cause an error, so please remove and check any special characters.
