### Agent Authorisation 64-8 Request

			Print

	Modified on: Thu, 17 Jun, 2021 at  5:08 PM

		Please click here to watch how use the agent authorisation tool

Location: Practice Management module > Workspace > Clients > Client Account > Agent Authorisation
Refer to the link

You can create and view new requests to HMRC for Agent Authorisation.

Help/Guide:

 - You can submit a new request to HMRC to become an agent of a particular client to make submissions on behalf of the client. 
 - Once there, choose the request you would like to send. For example Corporation Tax, PAYE and Self-Assessment.
 - Once you enter the details and send the request, HMRC will share a code with your client and you will need to get that code from your client and update in the 'status'. It will then verify with HMRC and the status will be updated to Authorised.
