### Uploading Multiple Documents in Practice Management

			Print

	Modified on: Tue, 30 Jun, 2026 at 12:38 PM

The maximum file/s upload is 20MB

Please also note, you can now upload zip files.

Creating a ZIP file allows you to:

Combine multiple files into a single file.
Reduce file size for easier sharing.
Upload multiple documents at once.
Keep related files organised in one place.
Speed up file transfers and downloads.

### Creating a ZIP File on Windows

Locate the files or folders you want to compress.
Select one or multiple files.
Right-click your selection.
Select Send to > Compressed (zipped) folder.
Windows will create a new ZIP file in the same location.
Enter a name for the ZIP file and press Enter.
Your ZIP file is now ready to be shared or uploaded.

### Creating a ZIP File on macOS

Locate the files or folders you wish to compress.
Select the required items.
Right-click (or Control-click) the selection.
Click Compress.
If you compress a single file, macOS creates filename.zip.
If you compress multiple files, macOS creates Archive.zip, which you can rename if required.
