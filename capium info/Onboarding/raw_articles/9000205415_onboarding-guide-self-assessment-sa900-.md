### Onboarding Guide: Self Assessment (SA900)

			Print

	Modified on: Fri, 15 Sep, 2023 at  4:30 PM

		This article will cover how you can create and submit the SA900 to HMRC

Video Tutorial:

Click here to watch how to create and submit a SA900 tax return 

Help Guide:

Creating the SA900 return

Navigate to the SA900 tab in the main dashboard and then select the trust. 

You will be able to create a new SA900 by clicking on '+SA900'.

You can then create the tax return as required.

Editing the Tax Return

To edit any of the information on the return, simply click on the link and enter the information. 

To add a supplementary page, click on the '+ Add Supplementary Page' button and select the page you want to add.

You can then add the information in accordingly 

Submitting the Tax Return 

To submit the tax return to HMRC, go back into the client dashboard and using the action dropdown box, select 'Submit To HMRC'.
