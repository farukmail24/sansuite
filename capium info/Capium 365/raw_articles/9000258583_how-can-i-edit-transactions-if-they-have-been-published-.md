### How can I edit transactions if they have been published?

			Print

	Modified on: Fri, 13 Dec, 2024 at  4:27 PM

		The Transaction will not be editable if it has been published. If a transaction has been published, you would have to “Unlock” the transaction. To do this go to: Books > Find the transaction > On the left-hand side there is an option to “Unlock” the transaction.

After this you can edit the transaction as usual. By clicking the pencil icon on the right hand side of the transaction labelled "Edit".
