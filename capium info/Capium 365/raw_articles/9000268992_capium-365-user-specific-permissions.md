### Capium 365: User Specific Permissions

			Print

	Modified on: Thu, 19 Jun, 2025 at 11:24 AM

		While general permission levels—Administrator, Manager, and Regular User—offer a structured way to manage team access across Capium 365, there are times when individual users require more tailored control. The User Specific Permissions feature allows you to override default access levels and customise permissions for each user as needed. 

If you're looking to set up overall access levels for your team, please refer to the General User Permissions Guide. That guide outlines how to manage roles more broadly before applying individual adjustments. 

Once a user has been added to the system, follow the steps below to amend their permissions directly within their profile. 

Navigate to Capium 365 > Manage > Users > Specific User 

To edit the user permissions, firstly click this drop down: 

This will allow you to choose what permission ranking the user should have: Administrator, Manager or Regular User 

To change what the permission allows, press the pen icon below the drop down.   

This page will pop-up:

You can change the permissions in here for that user. 

Once done you can Save, Save and Exit  

Note: Before assigning permissions in Capium 365, ensure that users are added to the system. After adding a user, scroll down to the bottom of their profile to configure their permissions as needed. 

For detailed instructions on adding users. Please refer to adding Users Guide.
