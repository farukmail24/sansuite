### Capium 365: Manage Imports (Users)

			Print

	Modified on: Wed, 8 Oct, 2025 at  7:00 PM

		Within the Capium 365 Manage Imports section, the import of clients, users, and templates helps you bring in the data efficiently. 

Click here to go to the Manage Imports page. 

Import of Users 

Users can be imported using the sample file method: 

1. Navigate to the Imports section. 

2. Select User as the type to import and press Next. 

3. Download the User sample file. 

4. Enter the required user information. 

5. Upload the completed file into the system. 

Once the file is uploaded, Capium 365 will automatically verify the data. After successful verification, the details of the clients will be displayed within the system.
