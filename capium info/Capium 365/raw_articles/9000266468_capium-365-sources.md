### Capium 365: Sources

			Print

	Modified on: Fri, 28 Feb, 2025 at  3:09 PM

The Sources feature within Capium 365 allows individuals and sole traders to track different streams of income efficiently. By categorising earnings into distinct sources, users can organise and report income accurately, ensuring compliance with financial and tax regulations.

Note: The Sources tab is only available for individuals and sole traders. If you are using a different entity type, this section will not be visible. Instead, transactions can be posted directly into the Bookkeeping module.

Adding a Source

### Navigation: Capium 365 Module > Select a Client (Individual or Sole Trader) > Click on Sources > Click on the "+ Add Source" button

### Click here to go directly to sources

### Please see below the steps of filling in a source

Fill in the required details:Source Type: Choose from UK Property, Foreign Property, or Self-employed business.
ID: Enter a unique identifier for the source.
Business ID: Provide the associated business ID.
Trading Name: Specify the trading name.
Accounting Type: Select the applicable accounting type.
Commencement Date: Enter the start date for this source.
Address Details: Include Postcode, House/Flat No, Street Name, City, County, and Country.
Non-FHL: If applicable, select this checkbox for non-furnished holiday lettings.

Click Save or Save and Exit to confirm the entry.

### Understanding the Sources Dashboard

Navigation: Capium 365 > Find the client you want to investigate > Click Go to 365 > Click Sources > The Sources dashboard provides a snapshot of income streams and profitability

Overall Sources Profitability: Displays total income, expenses, and net profit.
Source List:Source Code: A unique identifier for each source.
Source Name: The name associated with the income stream.
Type: Categorises the source (e.g., Foreign Property, UK Property).
Income & Expenses: Shows financial activity linked to each source.
Profit: Calculates net earnings per source.
Is Primary: Allows users to mark a primary income source.

### Reviewing Posted Data for a Source

### Navigation: Capium 365 Module > Select a Client (Individual or Sole Trader) > Click on Source > Once a source has been added and transactions are posted, you can review the associated data.

Please click here to go to the sources tab

### Subheadings in sources

Navigation: Capium 365 > Sources > Click into the source you want to investigate > Please see below different sub headings:

Profit & Loss Summary: View an overview of income, expenses, and net profit.
Income: Displays all income transactions linked to the source.
Expenses: Lists all expense records associated with the source.
Details: Provides comprehensive source information.
History: Logs modifications and updates made to the source.
