### Bulk Add Users via Excel (Only if no other modules are in use)

			Print

	Modified on: Thu, 24 Jul, 2025 at  2:17 PM

		To begin using Capium 365, it’s essential to correctly configure user access and complete their contact details. Below are the steps to follow for a smooth setup process.

Capium 365

Navigation: Capium 365 > Manage > Import

Begin by clicking on 'Users', then 'Next' to proceed. 

You will now have the option to download a sample Excel file, which serves as a template for uploading user data. This file includes the required format and columns needed for a successful import. 

Fill in the sample file with the appropriate user information, ensuring all required fields are completed accurately.
Note:  Refer to the image below for an example of the sample file structure.

Once the file has been populated, return to the platform to upload it. You can either:

Drag and drop the file into the upload area, or

Click 'Browse' to manually select the file from your device.

Note: You can drag and drop the file or click on browse.

The system will automatically validate the uploaded data. If there are any issues or missing fields, you will be notified so corrections can be made. 

Once the data has been verified and you're satisfied with the information, click 'Save and Next' to complete the import process.
