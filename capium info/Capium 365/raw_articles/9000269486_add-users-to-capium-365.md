### Add Users to Capium 365

			Print

	Modified on: Thu, 4 Sep, 2025 at  5:59 PM

		There are three available methods to import users into Capium 365. The choice depends on whether you’re using other Capium modules and how your firm manages user access.

Option 1: Add Users via My Admin (Recommended)

This is the most integrated and efficient approach:

When you assign users to clients through the My Admin section, those users are automatically imported into Capium 365.

This method is ideal if you’re actively using other Capium modules, as it ensures user access remains consistent across the platform.

Option 2: Bulk Add Users via Excel (Only if no other modules are in use) 

If your firm is not using any other Capium modules, you can bulk import users using a formatted Excel spreadsheet:

This method is helpful for setting up multiple users quickly.

Ensure the template is completed accurately to avoid upload errors.

Option 3: Add Users Individually in Capium 365 (Only if no other modules are in use)

For firms not using other modules, you can add users one by one directly within the Capium 365 interface:

Best suited for occasional user additions or when managing a smaller team.

Important Note:

For firms using multiple Capium modules, the My Admin method is the only approach that ensures full platform integration and proper user syncing across services.
