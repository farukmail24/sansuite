### Edit users in Capium 365

			Print

	Modified on: Thu, 24 Jul, 2025 at  4:27 PM

		Managing your team efficiently is key to smooth operations in any accounting practice. Capium 365 makes it easy to edit user details, update roles, and control access levels—all in just a few clicks. In this guide, we’ll walk you through the simple steps to edit users in Capium 365. 

Capium 365

Navigation: Capium 365 > Manage > User

There are 2 ways you can edit your users in capium 365:

By clicking on the users 'ID'
By clicking on the 'Pen' icon next to the user

ID

Firstly, click on the 'ID' number next to the user you wish to edit. This will open the user details, allowing you to make the necessary changes.  

Pen Icon

First, click on the 'Pen Icon' next to the user you wish to edit. This will open the user details, allowing you to make the necessary changes.
