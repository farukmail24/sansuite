### How do I resend or close a Document Request?

			Print

	Modified on: Thu, 24 Oct, 2024 at  4:54 PM

		If you go to: Documents > Requests > Click on the request you want to close or resend > In the top right corner, there are two options to either “Close” or “Resend” the request. 

If you resend the request, the end user will be notified that it has been resent. If the request is closed then this means that the end user will no longer be able to respond to it.
