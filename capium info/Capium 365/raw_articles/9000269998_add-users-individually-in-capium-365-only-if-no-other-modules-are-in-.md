### Add Users Individually in Capium 365 (Only if no other modules are in use)

			Print

	Modified on: Thu, 24 Jul, 2025 at  2:17 PM

		To begin using Capium 365, it’s essential to correctly configure user access and complete their contact details. Below are the steps to follow for a smooth setup process.

Capium 365 

Navigation: Capium 365 > Manage > Users

To add a new user individually, click on '+ Add User' 

You will now be able to enter the relevant user information. 

In this page you must add: 

 - Their first name 
 - Their email ID 
 - Their user permissions 

We recommend checking the box at the bottom to see if you want to assign this user to all future clients and/or all existing clients as these will be automatically checked on. 

Note: We recommend you add your users in the My Admin section in Capium if you have other modules, otherwise you can add them in this section.
