Accessing the Permissions Settings 

To manage permissions in Capium 365, follow these steps: 

Navigation: Manage > Permissions 

Click the dropdown icon to view all available permission types and associated user roles. 

User Types 

Admin Users – Have full access. 

Manage Users – Have limited view and access based on what's assigned. 

Regular Users – Have limited view and access based on what's assigned. 

Only Admins can see and manage everything. 

If needed, you can revert to the default permission settings by clicking the “Rest Default Settings” button located at the top right corner of the Permissions page. Please refer the above screenshot 

Customize Permissions for Individuals 

You can give specific access to a user if needed. For example, if someone needs access to the Import function: 

Navigate to:  Manage > Users 

Select the user whose permissions need to be modified. 

Under the "Manage Permissions" section, Click Edit user to change the user and save. 

By customizing permissions, you can ensure that a user (e.g., a manager) has full access to functionalities without granting them complete admin access. 

If you need further assistance in configuring user permissions, reach out to Capium support.
