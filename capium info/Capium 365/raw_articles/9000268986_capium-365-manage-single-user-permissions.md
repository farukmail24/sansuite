### Capium 365: Manage Single User Permissions

			Print

	Modified on: Fri, 4 Jul, 2025 at  4:19 PM

		Managing user permissions in Capium 365 is straightforward and allows you to control team access effectively. Here's a concise guide to help you navigate the process: 

1. Access the Permissions Section: 

Navigate to Capium 365 > Manage > Permissions. 

2. Understand Access Levels:  Capium 365 offers three distinct access levels: 

Admin Access: Full access to all areas  

Manager Access: Limited access  

Regular Access: Limited access 

3. Assign Permissions: 

For each user, you can set permissions by selecting: 

Full: Complete access to the module. 

View: Read-only access. 

None: No access to the module. 

Simply click on the corresponding checkbox to assign the desired permission level.
