### Capium 365 - Documents

			Print

	Modified on: Tue, 22 Oct, 2024 at  2:42 PM

Welcome to our Guide for Documents in Capium 365! This guide will walk you through essential initial steps, best practices and key features within Documents.

How to find document requests

Click on the three dashes in the top right-hand corner of the screen
Navigate to the “Documents” Tab
Select “Requests”

Folders

Capium 365 offers two different folders:

General – Folder for your personal use
Shared with me – Shared folder between you and your accountant

You can create new folders for your personal use: To do this, you need to:

Click on the three dashes in the top right-hand corner of the screen
Navigate to the “Documents” Tab
Select “Drive”
Click the “+” in the bottom right-hand corner of the screen
Select the “Folder +” icon in the bottom right-left hand corner of the screen
Type in the fo

You can star folders which will be shown in the drive and the starred tab.

How to upload documents

Navigate to the “Documents” Tab
Select “Drive”
Select the folder
Select the add icon
Select the file icon to upload the file

You can export folders. To do this you need to:

Navigate to the “Documents” Tab
Select “Drive”
Select the three dots in the right-hand corner
Select between Excel, CSV or PDF Format

How to delete a file

Navigate to the “Documents” tab
Select “Drive”
Select the folder
Select the three dots on the right-hand side
Select “Delete”

The deleted files can be found in the “Trash” section where they will remain for 30 days.

You can restore deleted files. To do this, you need to:

Navigate to the “Documents” Tab
Select the trash icon in the left panel
Select the three dots on the right-hand side
Select “Restore”

The document will be restored to its original folder.
