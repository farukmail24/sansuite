### Capium 365: Recording Multiple Properties with Different Ownership Splits

			Print

	Modified on: Wed, 15 Jul, 2026 at 12:57 PM

		Capium 365 is the right option for landlords who own several properties, each with a different ownership split. Rather than applying one flat percentage across a whole portfolio, Capium 365 lets you set an ownership percentage for each property individually, so every property's split is calculated correctly.

### Before you start

The landlord must be added and activated in Capium 365 at the individual level, not as a sole trader, because the Sources tab that holds property splits sits under the individual client record.

Navigation > Capium 365 > Select client (Individual)

### Adding a property with its own ownership split

Navigation > Capium 365 > Select client (Individual) > Sources > + Add Source > UK Property

Choose UK Property as the source type.
Enter the property's identifying details (ID, address, commencement date).
Set the ownership percentage for this specific property.
Save the source.
Repeat this for each property the client owns, setting the ownership percentage that applies to that individual property. For example, Property A might be set to 60%, Property B to 50%, and Property C to 30%, reflecting the client's actual share of each one.

See Capium 365: Sources for the full steps on adding and managing sources.

### How the calculation works

As you record income and expenses against each property source, always enter the full, gross figures for that property. Capium 365 automatically applies the ownership percentage set for that source, so only the client's correct share of income and expenses feeds into their MTD IT figures. This happens property by property, so a client with different splits on different properties does not need any manual calculation.

### When not to use this option

If a client's splits are simple and consistent across all their properties, for example every property is owned 50/50 with the same person, the ownership percentage field within MTD IT Bridging may be a simpler option that avoids purchasing Capium 365. See MTD IT: Setting Ownership Percentages for Property Splits in Bridging.

### Digital records still apply

Recording transactions in Capium 365 satisfies the digital record-keeping requirement for MTD IT, but the records must still be complete and accurate. HMRC can charge a penalty of up to £3,000 for a failure to keep digital records, or for breaking a digital link, for any given quarterly period. See MTD IT: Understanding Digital Records for the full requirements and penalty position.
