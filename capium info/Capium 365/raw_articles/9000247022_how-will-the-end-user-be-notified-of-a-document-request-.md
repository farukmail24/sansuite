### How will the end user be notified of a “Document Request”?

			Print

	Modified on: Thu, 24 Oct, 2024 at  3:35 PM

		Once an invite has been sent from the accountant, the end user will be sent an email notifying them of the request. The end user can then respond to the request within the end user app or web application.
