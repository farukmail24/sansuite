### Where can I see returned documents?

			Print

	Modified on: Fri, 25 Oct, 2024 at  3:18 PM

		You can see returned documents in two places. The first is in the invitation request. If you go to: Documents > Requests > click into a request. 

You can also see returned requests in the documents tab where a file will be created corresponding to the client’s name. Returned documents will be stored here by default. You Can see this by going to: Documents > Documents (Tab within it) Clicking the arrow in the middle of the page.
