### How do I upload invoices on Capium 365 web application?

			Print

	Modified on: Tue, 1 Apr, 2025 at 11:49 AM

		You can bulk upload up to 50 invoices at one time, as soon as you have uploaded 50 invoices, you can upload 50 more.

The file types that are supported and you can upload in Capium 365 are: JPG, JPEG, PNG, GID, BMP, AVIF, HEIF, WEBP, PDF. This is the same for purchase invoices and invoices. 

The files you can upload in are: JPG, JPEG, PNG, GID, BMP, AVIF, HEIF, WEBP, PDF.

There is no restriction on the file size you can upload in.
