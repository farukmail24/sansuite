### Can the end user upload invoices?

			Print

	Modified on: Fri, 25 Oct, 2024 at  3:37 PM

		Yes, the end user can upload invoices either. They can either do this on the web application or the mobile phone app. They would upload invoices in the customers section. They too can upload up to 50 receipts at one time.
