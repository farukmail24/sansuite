### Presenter ID and how to apply for a presenter account - from 03/06/2024

			Print

	Modified on: Tue, 4 Jun, 2024 at 11:27 AM

The service can be found on this GOV.UK page - Apply to file with Companies House using software - GOV.UK (www.gov.uk) - 

This new service is only available for users filing company accounts and documents that do not have a filing fee.  Users will still need to complete the relevant pdf forms if they wish to file documents with a fee (formations / CS01 etc.) or charge (mortgage registration).

Presenter Account Change, planned for 3rd June

If a user wishes to file company accounts and documents with Companies House using software, they will need to first apply for a presenter account.
As part of Companies House plans to move to software-only filing of accounts, they have modernised the process and replaced the existing pdf form with a new online automated service.
Users will be able to apply for and receive their presenter ID and code almost immediately, rather than having to wait up to 5 days for the request to be processed.
This service is only available for users filing company accounts and documents that do not have a filing fee.  Users will still need to complete the relevant pdf forms if they wish to file documents with a fee (formations / CS01 etc.) or charge (mortgage registration).
The link is https://www.gov.uk/guidance/apply-to-file-with-companies-house-using-software
