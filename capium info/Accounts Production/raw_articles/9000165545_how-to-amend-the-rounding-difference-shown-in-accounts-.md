### How to amend the rounding difference shown in accounts?

			Print

	Modified on: Fri, 31 Dec, 2021 at  3:38 PM

		Please note that when all the entries saved in a Trial Balance are not rounded perfectly, the system needs to do an auto-rounding to tally the accounts. This generates a minor value which goes to a designated account. The user can choose the rounding accounts as shown below. 

Navigation: Accounts Production Dashboard >> General Settings >> Report Format >> Other Settings 

Please note, accounts must be regenerated for the changes to reflect.
