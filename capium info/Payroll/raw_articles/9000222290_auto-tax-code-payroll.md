### Auto Tax Code- Payroll

			Print

	Modified on: Fri, 21 Apr, 2023 at  3:24 PM

		Navigation:

Manage Payroll > Auto tax code > Update tax code 

Help Guide:

Capium will now automatically pick up any changes made to the tax code at the start of a new tax year and update. To connect Capium to HMRC navigate into: Manage payroll > Auto tax code 

To authorise Capium click on 'Update tax code'.

Video Tutorial:

1. Navigate to Manage Payroll & Auto Tax code & then enter your HMRC PAYE credentials to pull tax code information into Capium. 

2. Navigate to Manage Payroll & Auto Tax code & then click 'Update tax code'

3. Then you select the tax codes you want to update the employee records & then click 'Apply'

The employees tax code will then be updated with the new tax code directly from HMRC.
