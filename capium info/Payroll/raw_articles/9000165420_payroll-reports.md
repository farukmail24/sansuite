### PAYE Calculator 

This Calculator shows you a projected PAYE report (Taxes and Net Pay) for the whole Tax Year (future periods) based on the Tax code, NI Category, Gross pay, Employer NI contribution, Employee NI contribution, the student loan of the Employee if any. All the details can be viewed for a particular Employee by selecting the same from the dropdown available on the upper left corner and a PDF of the calculation can also be downloaded by clicking on the upper right corner of the page.

The Pay Frequency can be selected from “Pay Frequency” drop-down menu.

You need to select an employee from the “Select Employee” drop down.

You can download a PDF version using the PDF icon on the top right.

### Payroll Summary

It shows the Summary of the Payroll submitted for a particular period. The Particular Period, Report Type, Pay Frequency etc. can be selected accordingly. Moreover, the same can be downloaded as a PDF or Excel sheet and you may also directly take a print or E-mail the same using the Icons available in the Upper Right Corner.

You may view the Report in summarised or detailed form. In summarised form, it shows the information of all the Employees altogether whereas in the detailed form it shows the per month calculations of the Employees.

You can select the Pay Frequency from the “Pay Frequency” drop-down menu.

You can select a particular time period to filter the results by setting the “From” and “To” dates.

You can view the report in two forms, Summarised and Details using the “Report Type” drop-down menu.

You can select the year from the “Year” drop-down.

You can view or download the report in the following ways;

PDF

Excel

Print

Email

### Periodic Tax & NI

This tab shows the summary of Tax and National Insurance Contributions and it also shows the Cost of Payroll. Export options are similar to other Reports.

You can select a particular time period to filter the results using the “From” and “to”date dropdowns.

You can select the relevant year using the “Year” drop-down.

You can view or download the report in the following ways;

PDF

Excel

Print

Email

### YTD Details

The YTD Details show the Gross Pay, Taxable Pay, PAYE Tax, Employee NI, Employer NI, Pension contributions. The Pay figures are also classified for NIC Computation purposes based on the prescribed limits.

Lower Earnings Limit (LEL)

Primary Threshold (PT)

Secondary Threshold (ST)

Upper Accrual Point (UAP)

Upper Earnings Limit (UEL)

They have various limits in terms of Pound per week, month and year.

Set the Pay Frequency from the “Pay Frequency” drop-down menu.

Set the particular Employee from the “Select Employee” drop-down menu.

You can select the year using the “Year” drop-down menu.

You can view or download the report in the following ways;

PDF

Excel

Email

### Additional Reports

In this section, you can view the details regarding the Additions and Deductions, Expense claims and Mileage Claims for a particular Employee. You may also download the details in the form of a PDF or Excel Report and also E-mail the same.

Set the Pay Frequency from the “Pay Frequency” drop-down menu.

You can select a particular time period to filter the results using the “From” and “To” dropdowns.

Set the particular Employee from the “Select Employee” drop-down menu.

You can select the year using the “Year” drop-down.

You can view or download the report in the following ways;

PDF

Excel

Print

Email

In the same way, you may find the other reports under Additional Reports Section

### Additional Form

In this section, you can find P45 and P60. 

P45: You may download a P45 for a client when he is leaving the organization. You need to mention the leaving date of the Employee under the Employee Information. The Employee will be shown accordingly as per the relevant period.

Set the Pay Frequency from the “Pay Frequency” drop-down menu.

You can select the year using the “Year” dropdown

You can view or download the report in the following ways;

PDF

Email

P60: You may provide a P60 to each of the Employee at the end of the Financial Year. The functionality and layout are the same as the P45 layout above.

### User Logs

In this User logs section, you may maintain the track of the actions and changes whatever you made in payroll.

You can search using this search bar to search through the User Logs.

You can search based on the user using the “User” filter.

You can select the time period by selecting the “From” and “To” dropdowns.

You can select the particular option of the “Action” from the “Action” drop-down filter.

### Email Logs

In this User logs section, you may find all the emails list which you have sent to your employees (i.e. Payslips, Pension Letters) etc.
