### Payroll Journal Automation

			Print

	Modified on: Thu, 10 Nov, 2022 at  8:58 AM

		Capium's payroll generates automatic journal entires at the end of each payroll submission. This article covers how to enable this feature. 

This feature automatically syncs data with Capium's bookkeeping, it also allows accountants to export journal entries from Capium to QuickBooks, Xero, FreeAgent, ClearBooks, and Sage. 

Navigation: Payroll >> Select a client >> Settings >> General Settings >> Edit >> Select 'Synchronise data with Bookkeeping'

Alternatively, you can click on this link to be redirected.  

Please Note: Automatic journal entires are created only after the above step-up is complete. Capium can't produce journals entires for past payroll submissions. Once this setting is enabled all subsequent payroll submissions will have corresponding journal entries.

Capium's bookkeeping module will automatically sync with the payroll module.
