### The payroll hasn&#39;t synced / synchronised with the bookkeeping module

			Print

	Modified on: Tue, 26 Mar, 2019 at 12:30 PM

		The journals will not be posted in the Bookkeeping module if the option ”Synchronize data with Bookkeeping” is not chosen. Please make sure that the option Synchronize data with Bookkeeping is selected under Settings >> General Settings >> PAYE Details tab.
