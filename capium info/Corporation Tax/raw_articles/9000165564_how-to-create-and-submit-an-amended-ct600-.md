### How to create and submit an amended CT600?

			Print

	Modified on: Tue, 30 Jun, 2026 at  5:30 PM

		Welcome to this quick guide on how to create an amended CT600. This guide will walk you through the essential steps.  

Amended CT600

Navigation: Corporation Tax > Client Specific > Tasks > CT600 Returns 

To create an amended CT600 return, first navigate to the Corporation Tax module and select the client you wish to create the amended return for.

Once you are in the client area, go to Tasks and select CT600 Returns. Click Create CT600 to create a new Corporation Tax return.

On the Create CT600 page,  under Return Type, change the value to Amended.

Complete any remaining return details as required, then click Save.

The system will create a new amended CT600 return, which you can then complete and submit in place of the original return.
