### How to create a CT600?

			Print

	Modified on: Mon, 25 Mar, 2019 at  4:40 PM

		Please follow the below steps to create a CT600 Return as desired:

●Create "Full" version of Accounts (not Abridged/Filleted, which is only meant for submission to Companies House) using the blue button named "+ Accounts" available on the top left side

Click here: Accounts Production >> Reports

●Once created, you may proceed to create the CT600 Return using the blue button available on the below page:

Click here: CT600 >> Tasks

●Please make sure you select the Full version of Accounts while creating CT600 Return, which you have already created under the Accounts Production Module.
